Security first

Your session never leaves your server

WhatsApp credentials stay on the machine that runs the bot. The website only ever sees a session you choose to copy.

🧂

scrypt hashing

Owner passwords are stored as salted scrypt hashes and compared in constant time.

🍪

HttpOnly cookies

Session tokens live in HttpOnly, SameSite cookies; only their SHA-256 hash is stored server-side.

🧾

Audit trail

Logins, lockouts, password resets and configuration changes are all recorded.
