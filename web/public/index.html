Core Features

Engineered for control & intelligence

Every toggle in the dashboard controls real bot behavior. No mock panels, no placeholder switches.

AYHA Auto-Reply

Answers private and group chats naturally. Supports quiet hours, contact allowlists, blocklists, and reply rate limiting.

Learned Tone & Style

Learns talking rhythm and vocabulary from your sent messages. Native support for English, Hindi, and Bengali/Banglish.

Protection & Moderation

Full suite of automated guards: Anti-call, anti-delete, anti-bot, anti-link, and private chat blocker.

Media Downloader

High-speed audio and video downloaders for YouTube, Spotify, Instagram, Facebook, TikTok, and Twitter.

Owner Security Console

Scrypt-hashed owner authentication, HttpOnly SameSite cookies, CSRF tokens, and automatic security audit logging.

Permanent Session Backup

Automatic atomic backups to session.card. Ensures zero reconnection prompts across server restarts.

Privacy Architecture

Your credentials stay on your server

WhatsApp authentication data is private. Lily MD never uploads credentials to Mega, Pastebin, or public servers.

Passwords

Scrypt Hashing

Owner credentials are protected with high-work-factor salted scrypt hashes and compared in constant time.

Session Card

Atomic Backups

Session data is atomically packed into session.card with 0o600 permissions and excluded from git.

Audit Trails

Security Logs

All authentication events, command executions, and configuration changes are recorded in the owner log.

Documentation & Setup

Deployment & Troubleshooting

Simple guides for hosting your bot on VPS, cloud containers, or linking via dual pairing.

VPS / Ubuntu Setup

Install Node.js 18+, clone the repository, run npm install, and start the daemon with PM2: pm2 start index.js --name lilymd.

Render Web Service

Deploy the website independently on Render with one click. Automatic HTTPS, custom domain support, and dedicated health monitoring.

Pairing Troubleshooting

If pairing fails with 401/403, ensure your phone has active internet and WhatsApp is updated. Use QR mode if phone code times out.
